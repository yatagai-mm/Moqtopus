## Requirements

- A C++17 compiler, CMake 3.21 or later, and Ninja (used by the vcpkg preset).
- A vcpkg checkout; the manifest resolves MsQuic and spdlog.
- A reachable relay that supports the MOQT version configured by your client.

Node.js is only needed to work on this documentation site. It is not a library dependency.

## Build and install

Run these commands from the repository root. Replace the two paths with your
vcpkg checkout and desired installation prefix.

```sh
export VCPKG_ROOT=/path/to/vcpkg
cmake --preset=vcpkg -DMOQTOPUS_BUILD_EXAMPLES=OFF -DMOQTOPUS_BUILD_TOOLS=OFF
cmake --build build
cmake --install build --prefix /path/to/prefix
```

## Link your application

```cmake
cmake_minimum_required(VERSION 3.21)
project(my_moq_app LANGUAGES CXX)

find_package(moqtopus CONFIG REQUIRED)
add_executable(my_moq_app main.cpp)
target_link_libraries(my_moq_app PRIVATE moqtopus::moq_subscriber)
```

The exported target includes **both** the subscriber and publisher APIs, despite
its name. It propagates the C++17 requirement and public include directory.
Configure your application with the installation prefix and vcpkg toolchain so
CMake can also find MsQuic and spdlog:

```sh
cmake -S . -B build \
  -DCMAKE_PREFIX_PATH=/path/to/prefix \
  -DCMAKE_TOOLCHAIN_FILE="$VCPKG_ROOT/scripts/buildsystems/vcpkg.cmake"
cmake --build build
```

When embedding the checkout directly, use `add_subdirectory(path/to/Moqtopus)`
and link the same target; make the dependency packages available through your
parent project's toolchain.

## Run the examples

From the repository root, enable and build the two example clients:

```sh
cmake --preset=vcpkg -DMOQTOPUS_BUILD_EXAMPLES=ON
cmake --build build --target subscriber publisher
```

Run the publisher and subscriber in separate terminals against your relay:

```sh
./build/publisher localhost 4433 camera/front video / moqt-18 stream
./build/subscriber localhost 4433 camera/front video / moqt-18
```

The examples are clients; these commands do not start a relay. The publisher
emits one object every 100 ms and starts a new group every 30 objects. Use
`datagram` instead of `stream` for datagram delivery. The CLI splits
`camera/front` into namespace fields; in C++, use `{"camera", "front"}`.

The example configuration uses the library default of disabled certificate
validation. For a verified TLS connection, set
`disable_certificate_validation = false` in your application and use a relay
with a certificate trusted by your system.

## Write a client

Follow the complete examples in [Subscriber](../subscriber/) and
[Publisher](../publisher/). For either role, wait for `ready()` after `connect()`
and handle exceptions from futures with `.get()`.

Include `moq/types.h`. All types on this page are in `namespace moq`.

## Identifiers and track names

| Type | Underlying type | Purpose |
| --- | --- | --- |
| `RequestId` | `uint64_t` | Identifies a request. Subscriber sessions allocate it. |
| `TrackAlias` | `uint64_t` | Maps received data to a subscription. |
| `GroupId` | `uint64_t` | Group within a track. |
| `SubgroupId` | `uint64_t` | Subgroup within a group. |
| `ObjectId` | `uint64_t` | Object within a group. |
| `ObjectStatusCode` | `uint64_t` | Wire object status, distinct from request/session errors. |
| `TrackNamespace` | `std::vector<std::string>` | Ordered namespace fields. |
| `TrackName` | `std::string` | Track name within a namespace. |
| `ByteBuffer` | `std::vector<uint8_t>` | Owned bytes. |
| `ObjectProperties` | `ByteBuffer` | Owned encoded property bytes. |

`Location` contains `GroupId group = 0` and `ObjectId object = 0`.
`{"camera", "front"}` and `{"camera/front"}` are different namespaces. Namespace
encoding allows at most 32 nonempty fields with at most 4096 total field bytes.

## BytesView

`BytesView` is a non-owning `{data, size}` pair. Construct it from a pointer and
length or a `ByteBuffer`. It provides `begin()`, `end()`, `empty()`, and
`to_owned()`; the last creates a new `ByteBuffer` copy.

The view never extends the backing storage's lifetime. In `on_object()`, both
`object.payload` and `object.properties` expire when the callback returns.
Copying `Object` itself only copies those views.

```cpp
#include <moq/types.h>

struct RetainedObject {
  moq::GroupId group;
  moq::ObjectId id;
  moq::ByteBuffer payload;
  moq::ObjectProperties properties;
};

RetainedObject retain(const moq::Object& object) {
  return {object.group_id, object.object_id,
          object.payload.empty() ? moq::ByteBuffer{} : object.payload.to_owned(),
          object.properties.empty() ? moq::ByteBuffer{} : object.properties.to_owned()};
}
```

Call `retain()` inside the callback, then transfer the owned result to your
application queue. Protect the queue if another thread consumes it.

## Received Object

| Field | Type | Meaning |
| --- | --- | --- |
| `request_id` | `RequestId` | Original subscription request. |
| `track_alias` | `TrackAlias` | Alias used by the data plane. |
| `group_id` | `GroupId` | Group containing the object. |
| `subgroup_id` | `std::optional<SubgroupId>` | Subgroup when the delivery format supplies one. |
| `object_id` | `ObjectId` | Object identifier. |
| `publisher_priority` | `uint8_t` | Publisher priority; default initialization is `128`. |
| `status` | `std::optional<ObjectStatusCode>` | Optional wire status; check it before treating the object as application data. |
| `properties` | `BytesView` | Borrowed encoded properties. |
| `payload` | `BytesView` | Borrowed payload bytes. |
| `delivery_kind` | `DeliveryKind` | Delivery format. |
| `stream_id` | `uint64_t` | Transport stream identifier for stream delivery; defaults to `0`. |

`DeliveryKind` defines `SubgroupStream`, `Datagram`, and `FetchStream`. The presence
of `FetchStream` in the enum does not imply a public FETCH API.

## Parameters

`Parameter` has `uint64_t type` and `ByteBuffer encoded_value`. Its static
factories encode the value according to the selected wire representation:

| Factory | Encoding |
| --- | --- |
| `uint8(type, value)` | One byte. |
| `varint(type, value)` | One MOQT variable-length integer. |
| `location(type, Location)` | Group followed by object, both varints. |
| `length_prefixed(type, ByteBuffer)` | Varint length followed by bytes. |
| `track_namespace(type, TrackNamespace)` | Encoded namespace tuple. |

Match the factory to the parameter's required representation. The helpers do
not infer it from `type`. Known identifiers live in `moq::codec`:

| Constant | Value | Representation |
| --- | --- | --- |
| `kParameterObjectDeliveryTimeout` | `0x02` | Varint |
| `kParameterSubgroupDeliveryTimeout` | `0x06` | Varint |
| `kParameterLargestObject` | `0x09` | Location |
| `kParameterForward` | `0x10` | Byte: `0` or `1` |
| `kParameterSubscriberPriority` | `0x20` | Byte |
| `kParameterSubscriptionFilter` | `0x21` | Length-prefixed filter bytes |
| `kParameterGroupOrder` | `0x22` | Byte: `1` ascending or `2` descending |
| `kParameterNewGroupRequest` | `0x32` | Varint |

For example, construct an absolute-start filter without hand-encoding integers:

```cpp
#include <moq/codec.h>
#include <utility>

moq::Parameter absolute_start(moq::Location start) {
  moq::ByteBuffer filter;
  moq::codec::write_varint(filter, moq::codec::kFilterAbsoluteStart);
  moq::codec::write_varint(filter, start.group);
  moq::codec::write_varint(filter, start.object);
  return moq::Parameter::length_prefixed(
      moq::codec::kParameterSubscriptionFilter, std::move(filter));
}
```

Filter constants are `kFilterNextGroupStart = 1`, `kFilterLargestObject = 2`,
`kFilterAbsoluteStart = 3`, and `kFilterAbsoluteRange = 4`. The first two contain
only the filter type. AbsoluteStart adds a start location; AbsoluteRange adds
the start location and an end-group delta. Filtering selects live objects and
does not request historical replay from the Moqtopus publisher.

## Request and completion records

| Type | Fields | Use |
| --- | --- | --- |
| `RequestUpdate` | `std::vector<Parameter> parameters` | Subscription update input. |
| `RequestOk` | `parameters`, `ObjectProperties track_properties` | Successful update result. |
| `RequestError` | `RequestErrorCode code`, `uint64_t retry_interval`, `std::string reason` | Decoded peer rejection. |
| `PublishDone` | `uint64_t status_code`, `uint64_t stream_count`, `std::string reason` | Publisher completion callback data. |
